# Data sources

* `data_full.json`, `domains.json`, `all_wiki_sents.txt` — **CLINC150 / oos-eval**
  S. Larson et al., *An Evaluation Dataset for Intent Classification and Out-of-Scope Prediction*, EMNLP-IJCNLP 2019.
  https://github.com/clinc/oos-eval — licensed CC BY 3.0. Files copied unchanged.
* `../appliance_intents.csv` — 100 hand-written home-appliance support messages (English + Turkish),
  5 intents, written for this homework (split 12 train / 3 val / 5 test per intent).
